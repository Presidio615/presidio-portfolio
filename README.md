# Presidio Mentor — Portfolio

## Files
- `index.html` — page structure/content
- `style.css` — responsive design and animations
- `script.js` — navigation, theme switcher, scroll effects and contact form

## Run
Open `index.html` directly in your browser, or use VS Code Live Server.

## Before publishing
Replace:
- `hello@example.com`
- `github.com/yourusername`
- the GitHub/LinkedIn URLs
- project descriptions/screenshots if desired

The contact form currently opens the visitor's email client using `mailto:`. For a real server-side form, connect it to your backend or a form service.
